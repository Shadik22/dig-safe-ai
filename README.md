# Dig Safe AI

### Prevent Underground Utility Damage Before You Dig.

## Problem
Underground water, gas, sewer, electrical and telecom utilities
can be damaged during excavation when their locations and
potential conflicts are not clearly visualized.

## Solution
Dig Safe AI is an AI-assisted excavation safety platform that
converts underground utility survey/GPR/GIS data into an
interactive risk map and helps identify potential conflicts
before digging.

## Key Features
- Interactive underground utility map
- Excavation-zone selection
- Risk analysis: Low / Caution / High
- Utility depth and distance information
- AI-assisted risk explanation
- What-if excavation planning
- Safety report generation

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Lovable

## Important Prototype Note
This hackathon prototype uses simulated underground survey data.
It does not physically detect underground utilities.
